# CodeGuard: SDLC Infrastructure Security Dashboard

## 1. Project Overview

CodeGuard is a proposed web-based security monitoring dashboard designed to help software development teams record, monitor, and manage security risks across the Software Development Life Cycle (SDLC).

The project is inspired by the SDLC Infrastructure Threat Framework (SITF), which identifies security threats affecting the systems and infrastructure used to develop, build, and deploy software.

## 2. Problem Statement

Traditional application security approaches often focus on vulnerabilities in the final software product. However, weaknesses in development environments, version control systems, CI/CD pipelines, software registries, and production infrastructure can also expose organizations to security risks.

CodeGuard aims to provide a centralized dashboard for tracking security findings across these areas and supporting informed risk management.

## 3. Project Objectives

- Monitor and categorize SDLC security findings.
- Classify findings according to severity and status.
- Visualize security metrics using charts and summaries.
- Support the tracking and management of security risks.
- Apply secure coding, automated testing, version control, and Lean Software Development principles.

## 4. Proposed Technologies

- **Programming language:** Python
- **Web framework:** Django
- **Data visualization:** Matplotlib
- **Version control and collaboration:** Git and GitHub
- **CI/CD:** Jenkins or CircleCI (to be selected)

## 5. Development Methodology

The project will apply Lean Software Development principles by prioritizing essential features, reducing unnecessary complexity, testing early, and improving the application incrementally.
